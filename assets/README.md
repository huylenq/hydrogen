# Brand icons

The three Icon Composer projects are the source of truth for full application icons:

- `dev/app-icon.icon`
- `nightly/app-icon.icon`
- `prod/app-icon.icon`

Each project uses `text.svg` for the Hydrogen H₂ mark (matching `apps/web/src/customizations/huy/HydrogenMark.tsx`) and `background.svg` when the background is a vector layer. Additional layers use semantic names that describe their role and placement.

Run `vp run icons:export` from the repository root to regenerate the tracked macOS, iOS, Linux, Windows, and web assets. The development web exports are also copied to `apps/web/public` for the browser favicon and splash screen. Run `vp run icons:check` to verify that the generated assets and public copies match their sources without changing files.

Exporting requires Icon Composer on macOS. The script selects the newest exporter from Xcode or a standalone Icon Composer installation. Version 2 pins design generation 26; version 1 (Xcode 26) uses its native preview exporter. Use the same Icon Composer version when running export and check. Set `ICON_COMPOSER_TOOL` to the full path of `Icon Composer.app/Contents/Executables/ictool` to override automatic discovery.

## macOS exports

`icons:export` renders each macOS icon body at 824×824 using Icon Composer, then centers it on a 1024×1024 transparent canvas with 100px margins and a soft shadow. The framing is scripted in `scripts/lib/icon-export.ts`, so exporting and checking all platforms works with Icon Composer 1 as well as 2, without the GUI-only `macOS pre-Tahoe` preset. The shadow is generated by the script, not the native pre-Tahoe renderer.

The generated files are:

- `dev/blueprint-macos-1024.png`
- `nightly/nightly-macos-1024.png`
- `prod/black-macos-1024.png`

`icons:check` includes these files. Restart the desktop dev runner (`vp run dev:desktop`) after exporting: its launcher regenerates the ICNS from the updated PNG and rebuilds the signed app bundle. Reopening the existing `.app` alone does not regenerate these files. Packaged apps receive the icon when rebuilt. The `.electron-runtime` icons and bundle are ignored build outputs; commit the source artwork and generated assets above instead.

Do not edit the generated PNG or ICO files directly.

## Android launcher and splash artwork

Android masks the central 72dp of a 108dp adaptive canvas, and the Android 12+ splash screen masks
the central two thirds of a 288dp canvas, so the Icon Composer exports cannot be used directly:
their rounded-square silhouette gets framed again and the wordmark is cropped. The Android artwork
is instead rendered from the same Icon Composer SVG sources by `vp run icons:export:android`:

- `apps/mobile/assets/android-icon-foreground.png`: the shared transparent wordmark, sized to stay
  inside the safe zone
- `apps/mobile/assets/android-icon-background-dev.png` and `-nightly.png`: full-bleed variant
  artwork (blueprint grid and annotations; night sky and clouds). Production uses a solid color.
- `apps/mobile/assets/android-splash-icon-*.png`: the two layers composed into one 288dp image, so
  the splash mask reproduces the launcher icon's framing.

Rerun the export after changing a layer SVG. The export also regenerates `android-icon-mark.png` for Android's monochrome themed icon
and `android-notification-icon.png` for notifications.
